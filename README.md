# نور القرآن 🌙

موقع لخدمة كتاب الله: قراءة المصحف الشريف بالرسم العثماني، واستماعه بأصوات كبار قرّاء العالم الإسلامي، مع ترجمات معتمدة بعدة لغات وتفسير مترجم.

## المميزات

- **المصحف كاملًا**: 114 سورة بالرسم العثماني (رواية حفص عن عاصم)
- **ترجمات معتمدة** مجمّعة حسب اللغة (إنجليزي، فرنسي، ألماني، تركي، أردية، إندونيسي، روسي، صيني وغيرها)
- **تفسير مترجم** (التفسير الميسّر) أسفل كل آية
- **عشرات القرّاء** بأصوات متعددة، مع تشغيل آية آية أو سورة كاملة أو تكرار آية محددة
- **حفظ تلقائي** للقارئ والترجمة المفضلة في المتصفح
- **متجاوب** مع الموبايل والتابلت والكمبيوتر

## التقنيات

- HTML + CSS + JavaScript خالص (بدون أي خطوة بناء)
- البيانات تُجلب لايف من [Islamic Network API](https://islamic.network/) (api.alquran.cloud)
- الصوتيات من CDN Islamic Network

## التشغيل محليًا

افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا محليًا بسيطًا:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub وارفع الملفات (`index.html`، `style.css`، `app.js`)
2. من إعدادات المستودع: **Settings → Pages**
3. في قسم **Source** اختر الفرع `main` والمجلد `/ (root)` ثم احفظ
4. بعد دقيقة تقريبًا سيكون الموقع متاحًا على:
   `https://اسم-المستخدم.github.io/اسم-المستودع/`

## تنبيه علمي

الترجمات المعروضة هي أشهر الترجمات المعتمدة لكل لغة، لكن لا توجد ترجمة بشرية «صحيحة ١٠٠٪» بالمعنى المطلق؛ فالترجمة اجتهاد يقارب المعنى، والعبرة بالنص العربي الأصلي.
